Why Beacon

Built for chat, not just clean sentences

Most language detectors are built for long, tidy text. Beacon is built for short messages, mixed scripts and Indian languages typed in Latin letters.

Romanised Indic

Tells Hinglish, Tanglish, Banglish and 9 more romanised South Asian languages apart, at 93% accuracy. Other detectors score close to 0% here.

No dependencies

Pure Kotlin inference. There is no ML Kit, TFLite or native code, and no Google Play services requirement. It adds about 8.5 MB to your APK.

Private & offline

The model ships inside the library on every platform. It makes no network calls, needs no permissions and sends no telemetry, so user text never leaves the phone.

Fast

About 0.08 ms per text on an Android emulator. That is fast enough to re-detect on every keystroke.

Install

Add it to your build

One line in your Gradle file, from Maven Central. Works in commonMain for Android, iOS, macOS, JVM desktop, JavaScript and WebAssembly. No API key, no account.

Maven Central live
// build.gradle.kts: commonMain, or any platform source set
dependencies {
    implementation("io.github.rajumark:beacon:2.0.0")
}

// Gradle picks the right artifact per platform:
// beacon-android · beacon-jvm · beacon-iosarm64 · beacon-iossimulatorarm64
// beacon-macosarm64 · beacon-js · beacon-wasm-js

Usage

Two lines to a language

Load once and reuse the instance. detect() is thread-safe.

Kotlin
val beacon = Beacon()

val r = beacon.detect("Kal milte hain bhai")
r.label      // "hin_Latn"
r.name       // "Hindi (romanised)"
r.isReliable // true

beacon.close()
Java
try (Beacon beacon = new Beacon()) {
    DetectedLanguage r =
        beacon.detect("Kal milte hain bhai");
    String label = r.getLabel();
}

API at a glance

MemberDescription
Beacon()Loads the bundled model. Implements AutoCloseable.
detect(text)The most likely language, or DetectedLanguage.UNDETERMINED when the text has no letters.
candidates(text, limit = 3)The most likely languages, best first.
supportedLabelsAll 211 labels, such as hin_Latn or tam_Taml.
DetectedLanguage(label, language, script, name, confidence)One result, with ISO 639-3 language and ISO 15924 script codes and isReliable.

FAQ

Questions

What is Beacon?

A Kotlin Multiplatform library (Android, iOS, macOS, JVM desktop, JavaScript, WebAssembly) that returns the language and script of a piece of text, from a list of 211 labels. That list includes all 22 scheduled Indian languages and 12 romanised South Asian languages.

What does "hin_Latn" mean?

Language plus script: Hindi (ISO 639-3 hin) written in Latin letters (ISO 15924 Latn). The same language in Devanagari is hin_Deva.

Does it run on device?

Yes. Inference runs entirely on the device in plain Kotlin. It makes no server calls, needs no network permission and sends no telemetry.

How does it compare to ML Kit Language ID?

On an Android emulator it scored 88.3% vs 71.3% on chat, 93.2% vs 84.0% on short text, and 92.1% vs 6.9% on romanised Indic. It also needs no Google Play services.

Is the Kotlin port exact?

Normalization, feature ids and predicted labels match the Python reference on all 958 test vectors, both on the JVM and on an Android device.

How much does Beacon cost?

Nothing for products with up to 10,000 monthly active devices per platform, including commercial apps. There is no API key or account, and no limit on how often it runs. Above that, a commercial license is needed. See Pricing.
